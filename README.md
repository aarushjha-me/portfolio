Aarush Jha - Portfolio Website
A modern, responsive portfolio website for Aarush Jha, a 9th grade student and aspiring aerospace engineer. This portfolio showcases his academic journey, skills, research publications, and future goals.

🌟 Features
Modern Responsive Design: Works perfectly on all devices (desktop, tablet, mobile)

Interactive Timeline: Visual representation of Aarush's academic and extracurricular journey

Research Highlights: Dedicated section for published work on Academia.edu

Goals Showcase: Interactive cards displaying future aspirations and projects

Social Integration: Links to GitHub, Instagram, Tinkercad, and Academia profile

Smooth Animations: CSS transitions and hover effects for enhanced user experience

Mobile-Friendly Navigation: Collapsible menu for smaller screens

🛠️ Customization Guide
Update Personal Information
Open index.html

Locate the hero section and update name/title

Modify the About Me section with your details

Update the timeline with your personal journey

Change Colors
Edit CSS variables in the :root selector:

css
:root {
    --primary-color: #1a237e;
    --secondary-color: #3949ab;
    --accent-color: #00acc1;
    /* ... other colors */
}
Update Social Links
Find the social links section in the footer and update URLs:

html
<a href="YOUR-LINK-HERE" target="_blank">
    <i class="fab fa-github"></i>
</a>
Add New Sections
Create a new section with unique ID

Add corresponding navigation link

Style using existing CSS classes
